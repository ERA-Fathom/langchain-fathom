# langchain-fathom is now langchain-right-rudder

Fathom is now Right Rudder, by Embedded Risk Analytics. This final release of `langchain-fathom` installs `langchain-right-rudder` and keeps `import langchain_fathom` and every `Fathom` class name working, with a deprecation warning. New code should install and import the new name.

```
pip install langchain-right-rudder
```

Source and documentation live at [github.com/RightRudderAI/langchain-right-rudder](https://github.com/RightRudderAI/langchain-right-rudder).
